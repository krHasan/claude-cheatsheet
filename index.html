Slash — Session & Context
/clearWipe conversation history & free context
/compactSummarize conversation to free context. Use /compact focus on tests to specify focus
/contextVisualize what is consuming your context window
/usageToken usage, API cost, plan limits. (/cost & /stats open tabs here)
/resumeResume a previous session. /resume auth-refactor
/renameName current session. /rename feature-auth
/rewindRoll back to a previous checkpoint
/branchBranch conversation into a parallel path
/diffView interactive diff of all changes made
/copyCopy last response. /copy 2 for 2nd-latest
/exportExport conversation as a text file
Pro tip: Use /compact when context usage exceeds 80%; use /clear when switching to an entirely new task.
⌥
Slash — Code & Project
/initInitialize project; generates CLAUDE.md with project context
/memoryView & edit CLAUDE.md and auto-memory files
/code-reviewReview diff for bugs. --fix applies fixes, --comment adds PR comments
/simplify3-agent parallel review (replaces deprecated /review)
/batchRun a bundle of tasks as a single compound command
/doctorDiagnose installation, auth, and config issues
/insightsView patterns and suggestions from past sessions
/goalSet a high-level goal for the session; tracks progress
/loopSchedule a recurring task (e.g., run tests every save)
/release-notesShow recent Claude Code version changelog
/hooksView configured automation hook events
Note: Custom slash commands: add .claude/commands/<name>.md in your project, invoke with /name.

Keyboard Shortcuts — Essential
Session Control
Ctrl+CInterrupt running op. First press clears input, second exits
EscInterrupt Claude mid-turn, keeping work done so far
Esc+EscClear input draft or open rewind menu for a checkpoint
Ctrl+DExit Claude Code
Ctrl+LRedraw screen (fix garbled display)
Ctrl+RReverse-search command history
Background & Agents
Ctrl+BMove running bash or agent to background (tmux: press twice)
Ctrl+X+KKill all background subagents (press twice within 3 s)
Ctrl+TToggle the task list panel
Ctrl+OToggle transcript viewer (detailed tool usage, MCP calls)
Modes
Shift+TabCycle permission modes: default → acceptEdits → plan → auto
Alt+PSwitch model (Opus / Sonnet / Haiku)
Alt+TToggle extended thinking
Alt+OToggle fast mode

CLI Flags & Options
Session Start
-p "query"Print mode — single query, then exit
-cContinue most recent session
-r "name"Resume a named / numbered session
-n "name"Set session display name at startup
--model opusOverride model for this session
--initInitialize project with CLAUDE.md
-wStart in an isolated git worktree
--fork-sessionFork from a resumed session
Automation & CI/CD
--max-turns 10Limit autonomous turns (great for pipelines)
--output-format jsonOutput as text, json, or stream-json
--allowedToolsRestrict tools. e.g., "Edit,Bash(npm:*)"
--permission-mode autoSet permission mode for the session
--enable-auto-modeStart with Auto Mode enabled
--from-pr 123Start session linked to a PR / MR / Bitbucket PR
--bareScripted mode — skip hooks, LSP, plugins
--dangerously-skip-permissionsSkip all permission prompts (use in trusted CI only)
Debug & Plugins
--debugEnable verbose debug logging
--channelsRelay approval prompts to Telegram / Discord
--plugin-dir ./pathLoad a plugin directory or .zip archive
--plugin-url https://…Fetch & load a remote plugin .zip

CLAUDE.md — Project Config
.claude/CLAUDE.mdProject-level instructions (auto-loaded)
~/.claude/CLAUDE.mdGlobal user instructions applied to every session
.claude/commands/Project custom slash commands (one .md per command)
~/.claude/commands/Personal global custom slash commands
.claude/settings.jsonProject permission & tool settings
~/.claude/settings.jsonGlobal user settings & defaults
What to put in CLAUDE.md: build & test commands, architecture overview, code conventions, folder structure, team preferences. Claude reads this at session start to stay aligned with your project.
